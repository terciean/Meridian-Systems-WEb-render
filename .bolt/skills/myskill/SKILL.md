# Skill: Professional Design, Typography, Color &amp; Anti-AI Slop Standards

## 1. Anti-AI Slop Guidelines (Zero-Tolerance Rules)

Avoid generic, overused AI aesthetic tropes ("AI slop") by enforcing authentic, high-craft design choices:

- **No Meaningless Neon Glows:** Do not throw random glowing gradients or multi-colored neon shadows behind every card or button. Glows should only be used for precise, functional focus states or intentional dark-mode highlights.
- **No Random Floating Blobs:** Avoid decorative, blurred background gradient blobs that serve no structural purpose. Layouts must be anchored with clean grids, whitespace, and sharp alignment.
- **Purposeful Layouts:** Do not default to the generic "three glowing feature cards with an icon, bold header, and gray paragraph" layout for everything. Vary card designs, use asymmetric layouts, editorial typography blocks, or lists where appropriate.
- **Intentional Spacing:** Avoid cramped padding or uniform, lazy spacing. Use generous, rhythmic whitespace (whitespace is a design element).

## 2. Color Design System

- **The 60-30-10 Rule:** 60% dominant background/surface color, 30% structural/text color, 10% intentional accent color.
- **Restraint Over Rainbows:** Limit the primary palette to 1–2 core hues plus neutrals. Never use high-saturation rainbow gradients haphazardly.
- **Contrast &amp; Accessibility:** Ensure all text meets WCAG AA contrast standards against its background. 
- **Sophisticated Neutrals:** Avoid pure black (`#000000`) on pure white (`#FFFFFF`) for large blocks of text; use soft off-whites and deep charcoal/slate tones for reduced eye strain and a premium feel.

## 3. Typography Hierarchy

- **Font Pairing Restraint:** Stick to a maximum of 1 primary typeface family (or 2 if pairing a distinct display/serif header with a clean sans-serif body). 
- **Proportional Scaling:** Establish a strict type scale (e.g., using modular scales like 1.25 or 1.333) rather than arbitrary font sizes.
- **Line Length &amp; Leading:** 
  - Body text line lengths should stay between 45–75 characters for optimal readability.
  - Set `line-height` (leading) proportionally: tighter for large headings (`1.1` to `1.2`), looser and more comfortable for body copy (`1.5` to `1.7`).
- **Tracking &amp; Weight:** Use tight letter-spacing (`tracking-tight`) for large bold headers to give them punch, and regular/open tracking for small uppercase or metadata labels.
