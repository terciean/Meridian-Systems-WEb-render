# Ethos Creative Systems

The approved split EC mark has matching middle arms. Keep the clear space around the lettering and use the full name in the header and footer.

| Asset | Use |
| --- | --- |
| `public/ethos-logo.svg` | Full wordmark with outlined lettering |
| `public/ethos-icon.svg` | EC favicon on the light brand surface |
| `public/ethos-social.png` | Social sharing image |

| Colour | Hex | Use |
| --- | --- | --- |
| Steel blue | `#507289` | EC initials, primary buttons and accents |
| Graphite | `#171B20` | Logo wording and strongest headings |
| Slate | `#242B33` | Main text |
| Silver | `#C8CED5` | Borders and dividers |
| Cool white | `#F7FAFD` | Page background |

Barlow Condensed carries the display typography. Source Sans 3 is used for body text and controls. Tailwind holds the site palette and type settings.
